## 工具

- [GoReport](https://github.com/chrismaddalena/GoReport)，作者：[Chris Maddalena](https://twitter.com/cmaddalena)。用于收集 GoPhish 活动数据并生成报告的 Python 脚本。
- [Phishbuckets](https://github.com/CommArc/phishbuckets)，作者：[snori74](https://github.com/snori74)。通过 API 调用管理 GoPhish 演练活动的命令行脚本。
- [Lure](https://github.com/highmeh/lure)，作者：[Jayme（highmeh）](https://twitter.com/highmeh)。用于收集并解析目标组织邮箱地址、再导入 GoPhish 的工具。
- [GoLDAP](https://github.com/md-howsa/GoLDAP)，作者：Mohammed AlHowsa。用于从 Active Directory 导入用户到 GoPhish 的 Python 脚本。
- [Phish Paste](https://github.com/glennzw/phishPaste)，作者：[Glenn Wilkinson](https://twitter.com/glennzw)。用于在不同 GoPhish 用户账户之间复制模板、页面和发送配置的小工具。
- [DW GoPhish Reporter](https://github.com/dwtechnologies/gophish-owa-phishing-reporter/)，作者：[Daniel Wellington Technologies](https://github.com/dwtechnologies)。协助终端用户报告钓鱼邮件的插件。
- [DW GoPhish Automation](https://github.com/dwtechnologies/dw-gophish-automation)，作者：[Daniel Wellington Technologies](https://github.com/dwtechnologies)。用于自动化内部钓鱼演练流程的项目。

> 这些是社区提供的外部资源，使用前应独立审查其安全性、授权范围与适用性。
