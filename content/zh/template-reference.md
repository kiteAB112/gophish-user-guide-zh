# 模板变量参考

以下变量可在模板和落地页中使用。

> 提示：模板变量**区分大小写**。

| 变量 | 说明 |
| :--- | :--- |
| {{.RId}} | 目标对象的唯一 ID |
| {{.FirstName}} | 目标对象的名字 |
| {{.LastName}} | 目标对象的姓氏 |
| {{.Position}} | 目标对象的职位 |
| {{.Email}} | 目标对象的电子邮件地址 |
| {{.From}} | 伪造的发件人 |
| {{.TrackingURL}} | 指向追踪处理程序的 URL |
| {{.Tracker}} | `<img src="{{.TrackingURL}}"/>` 的别名 |
| {{.URL}} | 钓鱼演练 URL |
| {{.BaseURL}} | 已去除路径和 `rid` 参数的基础 URL，适用于构造静态文件链接。 |
